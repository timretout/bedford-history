# UI sketches

Early mock-ups, drawn on a Claude design canvas. The `.dc.html` files are the
canvas sources (they need the canvas runtime, so they won't render standalone).

- **Main** — Google Maps–style explorer: place panel on the left, era filter
  chips, historic-map layer switcher, and a timeline docked along the bottom
  with eras drawn at equal width so recent centuries aren't squashed.
- **Timeline** — timeline-led layout: a map strip on top, numbered markers,
  and the eras as columns of event cards underneath.
- **Mobile** — bottom-sheet pattern with a compact era scrubber.

Places, dates and Wikipedia article titles are placeholder data to check
before use.
